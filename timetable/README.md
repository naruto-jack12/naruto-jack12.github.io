# 课程表（Timetable）

一个纯前端的可视化拖拽课程表制作工具：从顶部科目面板把课程拖进课表格子，排好后一键保存为图片。科目可自由增删改名，课表内容自动本地保存。

## 功能特性

- **拖拽排课**：三种交互 —— 从科目面板复制课程到格子、格内课程拖动/互换、拖回面板丢弃。
- **上下结构布局**：科目横向排成顶部一行（自动换行），课表表格在下方，课程多时观感更清爽。
- **科目可编辑**：默认科目来自 `data/subjects.json`；页面内可直接 **双击改名、点 × 删除、＋ 添加**（自定义名称与配色），修改结果存入 `localStorage`，之后优先读取本地版本。
- **本地自动保存**：每次拖放后课表内容写入 `localStorage`，刷新自动恢复；「清空课表」只清课表、不动科目，带二次确认。
- **保存截图**：基于 html2canvas 导出**标题 + 课表表格**（截图时临时隐藏顶部科目栏，不含科目），`scale: 2` 提升清晰度。
- **电脑端使用**：拖拽交互面向电脑浏览器；窄屏（≤1000px）自动隐藏课表并提示“请使用电脑端访问”。


## 运行方式

科目通过 `fetch('data/subjects.json')` 加载，**需要通过 HTTP 打开**（`file://` 下浏览器会拦截 fetch）。

```bash
cd timetable
python -m http.server 8201
# 浏览器访问 http://localhost:8201
```

> 兜底：若在 `file://` 下直接打开，`fetch` 失败时会自动使用 `script.js` 内置的默认科目列表，页面仍可正常拖拽（仅科目自定义受限）。

## 配置科目

**默认科目（data/subjects.json）**

```json
{
  "subjects": [
    { "name": "语文", "color": "#ff6b6b" },
    { "name": "数学", "color": "#4dabf7" }
  ]
}
```

- `name`：科目名称，显示在色块上（白色文字，建议选中等明度的颜色保证对比度）。
- `color`：色块背景色（十六进制）。留空则回退到默认色。
- 直接改这个文件可调整“出厂默认科目”，适合分发给所有人。

**页面内编辑（针对当前浏览器）**

- 双击某个科目 → 改名；点科目上的 × → 删除；点「＋ 添加科目」→ 输入名称 + 选配色后确定。
- 任何编辑都会整份写入 `localStorage`（key `timetable_subjects`）并**优先生效**；此后即使改了 `subjects.json` 也不会覆盖你本地编辑过的科目。若要回到默认，清掉该 `localStorage` 键即可。

## 交互说明

| 操作 | 结果 |
| --- | --- |
| 顶部科目 → 空格子 | 复制一份放入该格（面板原件保留，可重复使用） |
| 格子课程 → 空格子 | 移动过去 |
| 格子课程 → 已占用格子 | 两门课程**互换** |
| 格子课程 → 顶部科目栏 | 丢弃该课程（从课表移除） |
| 双击科目 | 修改科目名称 |
| 点科目上的 × | 删除该科目（二次确认） |
| 「＋ 添加科目」 | 输入名称 + 选颜色，加入科目栏 |
| 刷新页面 | 从 localStorage 自动恢复上次课表 |
| 「清空课表」 | 二次确认后清空课表格子（不影响科目） |
| 「保存课表截图」 | 导出 `课程表截图.png`（含标题，不含科目栏） |

## 技术要点

- **拖拽命中判定**：拖动时创建一个 `pointer-events: none` 的浮层（`.drag-ghost`）跟随指针，用 `document.elementFromPoint(x, y)` 取指针下方的真实落点，再向上冒泡找带 `data-allow` 的容器（`td`=copy / `.subjects`=move）。
- **触摸滚动冲突**：`.item` 设 `touch-action: none`，避免拖拽手势被浏览器当成页面滚动。
- **样式维护**：`scss` 与编译 `css` 两份都要改且保持一致（环境无 sass 编译器，css 为手工等价编译）。
