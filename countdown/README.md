# 精确倒计时

在线精确倒计时工具，精确到秒，支持自定义目标时间和快捷预设。

## 功能

- **精确到秒** — 每秒实时更新，带脉冲动画
- **自定义目标** — 手动选择日期时间
- **快捷预设** — 元旦、春节（1900-2100 全覆盖）、圣诞、1小时后、24小时后
- **进度条** — 渐变进度条显示已过时间占比
- **自动保存** — 数据保存在浏览器本地存储
- **明暗主题** — 右上角一键切换亮/暗，星空 + 霓虹风格，偏好自动记忆
- **SVG 图标** — 界面图标统一为线性 SVG（`assets/js/icons.js` 注册表，非 emoji）

## 使用

直接用浏览器打开 `index.html` 即可，无需服务端。

## 目录结构

```
countdown/
├── index.html           # 主页面
├── favicon.svg          # 站点图标
├── data/
│   └── presets.json     # 预设配置数据（icon 为图标名）
├── assets/
│   ├── css/style.css    # 样式（含明暗主题变量）
│   └── js/
│       ├── icons.js     # SVG 图标注册表
│       └── script.js    # 逻辑 + 主题切换
└── README.md
```
